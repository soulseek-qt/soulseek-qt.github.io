A newer macOS build

Soulseek released a refreshed macOS build with a newer Qt base, an updated interface style, improved dark-mode compatibility, and notarization.

The February 2021 macOS release was aimed at newer versions of Apple's operating system. It moved the client to a newer Qt version and introduced a refreshed interface style.

The release also addressed cut-off text in tab names, improved compatibility with macOS dark mode, and was notarized to work more smoothly with Gatekeeper on Big Sur.

Keeping the desktop client current

The macOS release illustrates the continuing maintenance required by a desktop application: operating-system changes can affect rendering, security checks, and compatibility even when the underlying network remains familiar.
